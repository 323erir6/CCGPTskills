# Як використовувати симулятор у звичайному ChatGPT

## Варіант 1 — ChatGPT Project

1. Створіть окремий проєкт ChatGPT.
2. Додайте `PROJECT_INSTRUCTIONS.md` як інструкції проєкту.
3. Завантажте `sable-chatgpt-bundle.zip` у джерела проєкту або безпосередньо в чат.
4. Увімкніть аналіз даних/Python, якщо він доступний у вашому режимі ChatGPT.
5. Почніть звичайний чат і напишіть, наприклад:

   `Створи JSON-сценарій падіння конструкції з висоти 20 блоків, запусти його та поясни всі обмеження точності.`

Проєкти ChatGPT передають чатам спільні файли та інструкції. Якщо використовується звичайний чат без проєкту, прикріпіть ZIP та потрібний `.json` до конкретної розмови.

## Варіант 2 — локально на Windows

З кореня розпакованого пакета:

```powershell
python -m agent.sim.chat_runner chatgpt/examples/drop_test.json --pretty --out report.json
```

Команда повертає код `0`, якщо всі assertions пройдені, `2` — якщо сценарій виконався, але перевірки не пройдені, і `1` — якщо вхідні дані помилкові.

## Важлива межа

Симулятор працює виключно з механіками Minecraft та конкретними модами. Слова на кшталт «двигун», «снаряд», «гармата» або «вибух» у цьому проєкті означають ігрові блоки, сутності й API. Інструкція уточнює контекст, але не вимикає правила безпеки ChatGPT. Не просіть перетворювати ігрові результати на реальні конструкції.

Якщо Python у чаті недоступний, ChatGPT може підготувати сценарій, але повинен чесно позначити його як `не виконано`.
