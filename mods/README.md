# Third-party peripheral adapters / Адаптеры сторонней периферии

**EN:** Add-on APIs are not part of core CC:Tweaked. Always record Minecraft version, mod version, peripheral type, method list and exact return-table shape from the installed environment. Modded API documentation is not a substitute for inspecting the actual device. The library includes [Advanced Peripherals Player Detector](advanced-peripherals.md) and [Generic physics/device probes](physics-and-devices.md).

**RU:** API дополнений не входят в стандартный CC:Tweaked. Всегда указывайте версию Minecraft, мода, тип периферии, список методов и точную структуру возвращаемых данных. Документация не заменяет проверку реального устройства. См. [Player Detector](advanced-peripherals.md) и [обнаружение физических устройств](physics-and-devices.md).

Generic probe / Универсальная проверка: [inspect_peripherals.lua](../examples/inspect_peripherals.lua).
