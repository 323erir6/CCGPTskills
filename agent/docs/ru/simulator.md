# GOCODE — детерминированный симулятор Minecraft/CC:Tweaked

Это **текстовая тестовая среда на Lua 5.3** для воспроизведения ошибок и проверки исправлений программным агентом. Долгосрочная цель — максимально точно реализовать необходимые механики Minecraft 1.21.1, NeoForge и установленных модов. **Текущая реализация не является полной копией** Minecraft, Sable, Rapier или модпака.

## Устройство

- \`agent/sim/world.lua\` — разреженный мир блоков, твёрдость и отметки жидкости, положение конструкции, масса, линейная и угловая скорость, силы, моменты, гравитация, сопротивление, кватернионы, непрерывная проверка столкновений с блоками и между двумя движущимися сферами.
- \`agent/sim/engine.lua\` — **20 игровых тиков в секунду** и отдельная настраиваемая частота физических подшагов (по умолчанию **120 Гц**). Обработчики событий, отложенные действия, выходы редстоуна и журнал их изменений.
- \`agent/sim/cc.lua\` — искусственные компьютеры с реестром периферии, rednet, очередью таймеров, \`getLogicalPose\` / \`getVelocity\`, а также \`getPhysicsState\` / \`applyControlImpulse\` в форме методов Enhanced Detector Radar.
- \`agent/sim/text.lua\` и \`run.lua\` — предсказуемая текстовая выдача JSON без графики.
- \`agent/sim/compare.py\` — сравнение эталонного и рассчитанного JSON по каждому полю, с настраиваемой абсолютной и относительной погрешностью.
- \`agent/sim/coverage.json\` — машинный список **реализованных и отсутствующих механик**.

API Sable в симуляторе обслуживает искусственная физическая модель. Это **не настоящая реализация Sable**. \`applyControlImpulse\` предполагает линейный импульс в условных единицах и угловой импульс относительно момента инерции однородной сферы. Совместимость соглашений с реальным модом нужно проверять отдельно.

## Физическая модель

**Блоки:** целочисленные координаты; отсутствующий блок — воздух. \`setBlock(x,y,z,true)\` размещает сплошной куб. Поддерживаются идентификатор блока и простой флаг твёрдости. Потоки жидкости, чанки, реальные формы блоков и их внутриигровые обновления пока не реализованы.

**Движение:** глобальные координаты, предполагаемое соответствие одного блока одному метру. Ускорение по умолчанию \`(0,-9.81,0)\` блок/с². Это **настраиваемый параметр инженерной модели, а не подтверждённая константа Sable**. Используется полунеявный метод Эйлера: сначала обновление скорости, затем координат. Экспоненциальное сопротивление уменьшает скорость; силы и моменты сбрасываются после подшага.

**Повороты:** нормализованный кватернион \`{w,x,y,z}\`, угловая скорость в рад/с относительно мировых осей, интегрирование по \`dq/dt = 0.5 * omega * q\`. Момент инерции приближён формулой сферы \`I = 0.4 * mass * radius²\`. Настоящие корабли Sable имеют другую геометрию.

**Столкновения:** пересечение траектории сферы с расширенной прямоугольной границей блока (приближение) и непрерывное пересечение двух сфер. Это позволяет проверять отдельные случаи пролёта через препятствия на высокой скорости. Не реализованы полноценные сложные формы, соединения, тензоры инерции, контактные многоугольники, точный решатель трения, баллистическое пробитие и взрывы CBC. Если поиск охватывает слишком много блоков, тест завершается ошибкой, а не молча пропускает препятствие.

**Время:** игровые события и таймеры привязаны к 20 TPS; физика выполняется с частотой \`physicsHz\`, кратной 20. Реальный порядок выполнения Minecraft, CC:Tweaked и потоков Sable пока не воспроизводится.

## Команды

Из корня репозитория:

\`\`\`sh
lua5.3 agent/tests/test_world.lua
lua5.3 agent/sim/run.lua agent/scenarios/falling_block.lua
python3 -m unittest discover -s agent/tests -p 'test_*.py'
\`\`\`

Сценарий должен быть **доверенным Lua-файлом**, заранее добавленным в \`agent/scenarios/\`. После успешного запуска выводится JSON со статусом, номером тика, координатами, скоростями и счётчиками контактов. Неуспешное утверждение завершает тест ненулевым кодом.

Пример:

\`\`\`lua
return {
  options={physicsHz=120},
  ticks=20,
  setup=function(engine)
    engine.world:setBlock(0,0,0,true)
    engine.world:addBody({position={x=0,y=5,z=0},mass=10,radius=0.3})
  end,
  assertions=function(engine)
    assert(engine.world:getBody(1).position.y < 5)
  end
}
\`\`\`

Для сравнения с измерениями из Minecraft:

\`\`\`sh
python3 agent/sim/compare.py reference.json simulated.json --abs 0.01 --rel 0.001
\`\`\`

Структуры двух JSON должны совпадать. Эталон можно получать только из фактически проверенного источника или измерений; нельзя обозначать искусственно созданные данные как измерения Minecraft.

## План достижения высокой точности

1. Записать реальные трассы Minecraft 1.21.1 и Sable 2.0.5 для движения, ориентации, импульсов, углового ускорения и порядка тиков. Фиксировать версии модов, массу, геометрию, исходные условия и seed.
2. Вместо одной сферы моделировать столкновения объединений вокселей и тензоры инерции; добавить ускоренные структуры поиска столкновений и контактный решатель.
3. Отдельно воспроизвести планировщик CC:Tweaked, события, распространение редстоуна, кинетические сети Create и работу чанков на основании реального кода.
4. Добавить адаптеры NeoPeripheral, Create:Aeronautics, CBC, Advanced Peripherals и остальных модов с проверкой контрактов и эталонными трассами.
5. Реализовать сущности, инвентари, block entities, жидкости, урон, взрывы, снаряды и незагруженные чанки после верификации каждой механики.
6. Для каждой части явно указывать статус: \`mock\`, \`approximation\`, \`source-confirmed\`, \`trace-verified\`. Синтетический тест сам по себе **не подтверждает работу в настоящем Minecraft**.

Объём модпака не позволяет сейчас честно заявить о полной эквивалентности. Реальный перечень возможностей описывает файл \`agent/sim/coverage.json\`.
