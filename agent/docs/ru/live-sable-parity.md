# Сверка пассивной физики Sable и Minecraft

**Область проверки:** только свободное падение одного инертного блока и контакт с ровной поверхностью. Не включает управляемый полёт, двигатели, наведение и поражение целей.

Тест JNI с оригинальным Sable/Rapier не доказывает соответствие текущему серверу Minecraft. Новый шлюз качества запрещает положительный вывод при отсутствии независимо измеренных игровых данных.

## Процедура

1. Выполнить `python3 -m agent.validation.native_conformance --jar /path/to/sable-neoforge-1.21.1-2.0.5.jar --cases 12 --runs 5 --output agent-results/native-passive.json`.
2. Независимо записать на сервере те же 12 начальных условий в пяти отдельных запусках: массу, начальное положение, конечное положение и три компоненты конечной скорости. Время должно быть подтверждено серверными тиками, не выводиться из `os.clock()`.
3. Сформировать `minecraft-passive.json` по схеме в [английском руководстве](../en/live-sable-parity.md), указав действительные отпечатки модпака и конфигурации. Не копировать значения из симулятора.
4. Выполнить `python3 -m agent.validation.live_parity --native agent-results/native-passive.json --live agent-results/minecraft-passive.json --out agent-results/passive-parity.json`.

При отсутствии игрового журнала статус **`not_qualified`**, код выхода 1. При совпадении предоставленных данных статус `passive_parity_consistent`, но это относится только к проверенному пассивному сценарию. Происхождение вручную загруженного файла не может быть криптографически удостоверено этим скриптом. Точность управляемой ракеты этими тестами не подтверждается.
