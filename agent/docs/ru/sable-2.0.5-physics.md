# Физика Sable 2.0.5: исходники конкретной сборки Minecraft 1.21.1 NeoForge

Исходная версия подтверждена **не по названию в интернете, а по JAR из модпака**: `sable-neoforge-1.21.1-2.0.5.jar`, SHA-256 `c8710f85bc780bbf523e6726ceaaf76dd0b8c61479db497b382c6bb34317e7ab`. Внутри вложенного JAR `sable_rapier` есть оригинальные нативные библиотеки Rapier. Их **не копируем** в репозиторий и пока не запускаем напрямую.

Версионные источники: [Sable 2.0.5](https://github.com/ryanhcode/sable/tree/mc1.21.1-2.0.5-neoforge) (коммит релиза `6966d29`), [Rust-бэкенд Sable](https://github.com/ryanhcode/sable/blob/mc1.21.1-2.0.5-neoforge/sable_rapier/src/main/rust/rapier/src/lib.rs), [параметры контактов](https://github.com/ryanhcode/sable/blob/mc1.21.1-2.0.5-neoforge/sable_rapier/src/main/rust/rapier/src/hooks.rs). Форк Rapier зафиксирован на [коммите `38e92f117590862481a53df6fc69a5d893e29186`](https://github.com/ryanhcode/rapier/tree/38e92f117590862481a53df6fc69a5d893e29186).

## Точные значения по исходному коду

| Параметр | Стандартное значение |
|---|---:|
| Гравитация | `(0,-11,0)` блок/с² |
| Общее линейное и угловое затухание | `0.09` |
| Подшаги физики на игровой тик | `2` (при 20 TPS получается 40 Гц) |
| Трение физической конструкции | `0.525` |
| Трение неподвижного мира (значение Rapier по умолчанию) | `1.0` |
| Множитель трения блока | `1.0`, если не переопределён |
| Возврат энергии после удара (restitution) | `0`, если не переопределён |
| Максимальные дополнительные CCD-подшаги | `3` |
| Пружинные контактные параметры | частота `30`, демпфирование `5` |

Конфигурация сервера может изменить часть значений. Параметры, заданные по умолчанию в Java, не всегда тождественны использованным настройкам нативного решателя.

## Формулы, перенесённые из Rapier

В форке Rapier демпфирование происходит **делением**, а не умножением на экспоненту:

```text
v_next = v_pre / (1 + drag * dt)
```

Для изолированного тела без контактов в простейшей схеме интегрирования:

```text
v_pre = v_old + gravity * dt
x_next = x_old + v_pre * dt
v_next = v_pre / (1 + drag * dt)
```

В стандартном правиле Rapier коэффициенты трения двух коллайдеров усредняются:

```text
mu = ((0.525 + 1.0) / 2) * friction_block_A * friction_block_B
   = 0.7625  при стандартных множителях блоков
```

Тангенциальный контактный импульс ограничен условием `abs(J_t) <= mu * J_normal`. Настоящий Rapier дополнительно вычисляет реакции во всех контактных точках, инерцию вращения, стабилизацию, повторные итерации и накопленные импульсы. **Текущий симулятор ещё не воспроизводит эти механизмы точно.** Его упрощённое трение о плоскость не следует выдавать за результат нативного Rapier.

## Использование

В модуле `agent/sim/rigid.py` запустите `World(profile="sable-2.0.5", ground_y=168)`. Профиль выбирает 40 Гц, гравитацию −11, затухание 0.09 и базовое трение 0.7625. Все тесты запускаются без графики:

```sh
python3 -m unittest agent.tests.test_sable205 -v
python3 -m unittest discover -s agent/tests -p 'test_*.py'
```

Для ранее заданного теста (поверхность Y=168, центр куба `(0,300,0)`, начальная скорость `(0,0,5)`) приближённая контактная модель даёт остановку примерно на `(0,168.5,21.556)` через `5.65` секунды. **Это расчёт нашего приближённого алгоритма, а не проверенное измерение из Minecraft.**

Библиотеки нативного Sable Rapier внутри JAR имеют интерфейс JNI и используют Java-сцены, коллайдеры и состояние мира. Напрямую вызвать их из Python как обычную библиотеку нельзя. Для достоверной контактной физики нужен отдельный JNI-адаптер с реальными объектами физического движка или проверенные записи работы того же модпака. Исходные лицензии стороннего кода необходимо соблюдать.
