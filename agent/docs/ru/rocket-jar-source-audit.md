# Источники и bytecode физики ракеты: точная сборка Sable 2.0.5

Теперь симулятор получает настоящие формы блоков из установленных JAR через `javap` и передаёт их в оригинальный Sable/Rapier через JNI. Данные сохраняются как текстовый JSON без графики.

Проверены `createpropulsion-1.1.5.jar`, вложенный `simulated-nested.jar` из Create Aeronautics 1.3.2, `createbigcannons-5.11.7+mc.1.21.1.jar` и схема `rszo_rocket_v0.nbt`.

Геометрия: у твердотопливного двигателя **5** отдельных компонентов формы, у симметричного паруса толщина 4/16 блока, HE-снаряд имеет поперечник 10/16 блока. Ориентация формы рассчитывается из свойств блока в NBT. Для компьютера и автономного загрузчика чанков пока используется полный куб с предупреждением — их фактические состояния в Minecraft не подтверждены.

Движение решает оригинальная библиотека Sable. Тяга двигателя, аэродинамическое сопротивление и состояния блоков исполняются **адаптером Python**, а не оригинальным игровым циклом Java.

Из байткода подтверждены параметры угольного блока: время 16000 тиков, множитель тяги 1.15, базовая тяга 200, время запуска 10 тиков; у паруса параллельное сопротивление 1.75, сопротивление во всех направлениях 0.068882026, подъёмная сила 0. Выход двигателя требует питания. NBT **не включает двигатель**: у него `RedstoneInput=0`, у компьютера `On=0`. Для тестового полёта требуется отдельная команда зажигания.

Перенесена формула тензора инерции из Sable `MassTracker`: собственная диагональная инерция блока `m/6` и добавка переноса `m * ((r·r)I - rrᵀ)`. Сохранённая масса 4.5 — справочная и требует проверки с реально загруженными datapack и конфигами.

Подробные источники, точные команды, отсутствующие механизмы и ограничения точности — [English version](../en/rocket-jar-source-audit.md). Проверки в `agent/tests/test_rocket_source_profile.py`.

## Проверенная масса и тензор инерции по установленным модам

Добавлен `rocket_mass_registry.py`, который читает настоящие
`data/*/tags/block/*.json` и определения массы из JAR Sable и модов,
раскрывает вложенные теги и применяет приоритеты определения физических
свойств. Симметричные паруса `simulated:white_symmetric_sail` включены в
`create:windmill_sails` и затем в `sable:super_light`, то есть масса каждого
паруса равна **0.25**. Четыре остальных блока имеют стандартную массу 1.0
по этим ресурсам.

Общая масса **4.5**, что независимо подтверждает сохранённое значение в NBT.
Центр масс `(0.5,0.5,3.0)`, инерция `(17.875,17.875,0.75)` вместо неверно
принятых ранее `(13.875,13.875,0.75)`. Для использования JAR-данных
добавлены параметры `--simulated-jar`, `--cc-jar`, `--chunk-loader-jar`.

Новый пример с оригинальным нативным Rapier и рассчитанной по тегам
инерцией даёт первое столкновение примерно на **186.475 с**, контактная
точка `(10,168,97004)`, а центр тела в конце шага
`(13.325,168.027,97016.172)`. Это **не точный проверенный результат игры**:
серверные datapack, Java BlockEntity, две неизвестные формы, загрузчик чанков
и взрыватель всё ещё не выполняются. Результат **14.825 с**, вычисленный
раньше с одинаковой массой блоков, неверен для новых проверенных параметров.
