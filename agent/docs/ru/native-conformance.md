# Проверка повторяемости нативного Sable 2.0.5

Это **тест нейтральной физики без графики**, а не сертификация полёта,
наведения или эквивалентности Minecraft. Используется настоящий Rapier из
локального JAR Sable 2.0.5; нативные бинарные файлы не распространяются.

## Методика

- 12 независимых кубов 1x1x1 с различной массой и начальной высотой;
  поверхность мира Y=168.
- 160 физических шагов по 1/40 с; гравитация -11 и затухание 0.09.
- Три независимых повторения: всего 36 испытаний столкновения.
- Измеряются ошибка высоты относительно Y=168.5, горизонтальное смещение,
  остаточная скорость и различие результатов между повторами.
- Отсутствие JAR, некорректные данные, превышение порога или пропущенные
  объекты приводят к ошибке. Никакие значения не заполняются приблизительно
  вместо отсутствующих фактических измерений.

## Запуск

```sh
python3 -m unittest agent.tests.test_native_conformance -v
python3 -m agent.validation.native_conformance \
  --jar /path/to/sable-neoforge-1.21.1-2.0.5.jar \
  --runs 3 --cases 12 --output agent-results/native-conformance.json
```

Пороги **только для этого теста**: вертикальная ошибка <=0.035 м,
горизонтальный дрейф <=0.25 м, остаточная скорость <=0.02 м/с,
повторяемость <=0.01 м.

**Совпадение с игрой не проверено**: моделирование блоков модов, Java-тиков,
чанков и внешних API в эту проверку не входит. Полёт и наведение также не
тестируются.
