# Runnable samples / Запускаемые примеры

| Example | English | Русский |
| --- | --- | --- |
| [inspect_peripherals.lua](inspect_peripherals.lua) | List type and methods of connected devices | Перечисление типов и методов |
| [rednet_receiver.lua](rednet_receiver.lua) | Protocol-filtered receiver | Приём сообщений по протоколу |
| [rednet_sender.lua](rednet_sender.lua) | Protocol-based sender | Отправка сообщений |
| [monitor_dashboard.lua](monitor_dashboard.lua) | Responsive terminal-style monitor | Интерфейс монитора |
| [redstone_pulse.lua](redstone_pulse.lua) | Bounded redstone output pulse | Импульс редстоуна |
| [turtle_safe_move.lua](turtle_safe_move.lua) | Conservative turtle movement | Безопасное движение черепахи |
| [player_detector.lua](player_detector.lua) | Optional add-on with version probing | Пример со сторонним детектором игроков |
| [control_simulation.lua](control_simulation.lua) | PID simulation without an actuator | Симуляция PID без привода |
| [position_speed.lua](position_speed.lua) | Speed computed from position samples | Скорость по измерениям позиции |

**EN:** For rednet demo, run receiver on one computer and sender on another (`rednet_sender <computerId>`). Modems must be available and connected. Some examples require optional peripherals. Verify each example on the target CraftOS version.

**RU:** Для Rednet запустите приёмник на одном компьютере, отправитель — на другом (`rednet_sender <computerId>`). Нужны модемы и связь. Часть примеров использует дополнительные устройства. Проверяйте работу с конкретной версией CraftOS.
