# GOCODE engineering infrastructure

The CC:Tweaked coding agent toolkit is located at [agent/docs/en/README.md](../../agent/docs/en/README.md). It includes CI, mocks, structured API manifests, deterministic benchmarks, engineering context and pull-request workflows.

This is a development helper, not a CC:Tweaked peripheral or a standalone language model.

For task-bounded iterative execution, prefix a request with `[goloop]` on its own line and follow it with a task checklist. See [continuous execution rules](../../agent/docs/en/README.md#11-goloop--continuous-execution-for-a-checklist). This does not remove execution limits.
