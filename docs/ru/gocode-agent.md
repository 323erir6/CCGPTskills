# Инфраструктура GOCODE для разработки

Набор инструментов программного агента для CC:Tweaked описан в [agent/docs/ru/README.md](../../agent/docs/ru/README.md). Он включает CI, имитации периферии, структурированные API, регрессионные тесты, контекст проекта и работу через pull requests.

Это инструмент разработки, а не периферия CC:Tweaked и не отдельная языковая модель.

Для итеративного выполнения списка задач начните сообщение с `[goloop]` отдельной строкой и перечислите задачи. Подробнее: [циклическое выполнение](../../agent/docs/ru/README.md#11-goloop--циклическое-выполнение-списка-задач). Маркер не отменяет ограничения платформы.
