# Стандарты наполнения библиотеки

Цель — автономный справочник CC:Tweaked с подтверждёнными источниками, доступный даже при отсутствии внешних сайтов документации.

## Обязательное содержание разделов API

Каждый модуль должен содержать:
1. Точное имя установленного JAR, идентификатор и версию мода, если известны.
2. Исходный репозиторий и коммит либо указание на проверенный байткод установленной версии.
3. Тип интеграции: глобальный Lua API, generic peripheral, IPeripheral, расширение Mixin или просто физический патч.
4. Точные методы Lua, типы и порядок аргументов, скрытые Java-аргументы, возвращаемые значения и ошибки.
5. Схемы таблиц, типы полей, единицы измерения, необязательные поля и системы координат.
6. Серверные настройки, пределы, разрешения и аппаратные условия.
7. Небольшие завершённые примеры без выдуманных API.
8. Особенности версий и совместимость с другими модами сборки.
9. Тесты, ожидаемые результаты и честный статус проверки.

## Полное разделение языков

Текст на русском хранится только в `docs/ru/`, английский — только в `docs/en/`. Пары документов должны содержать **одинаковые** имена методов, диапазоны, аргументы и поля, но каждое описание пишется отдельно на своём языке. Исходники `lib/` — общие выполняемые модули, а не языковые версии документов.

## Надёжность

Подтверждайте доступные команды через `peripheral.getMethods`. Наличие Java-метода в байткоде не гарантирует его экспорт в Lua. Изменение состояния игровых устройств должно проверять параметры и разрешения. Пересказывайте технические факты своими словами, не копируя большие чужие справочники.

## Тесты

Успешный CI означает проверку синтаксиса и чистой математики, но не проверку реальной периферии в Minecraft. Не объявляйте игровое тестирование пройденным без соответствующих данных.
