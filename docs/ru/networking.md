# Сети и протоколы сообщений

## Rednet

Rednet передаёт сообщения через модемы. Сначала открывается модем командой `rednet.open(sideOrName)`. Для беспроводных узлов нужен беспроводной модем. `rednet.send(id, payload, protocol)` отправляет сообщение конкретному компьютеру; `rednet.receive(protocol, timeout)` возвращает отправителя, содержимое и протокол либо `nil` по тайм-ауту.

**Rednet не обеспечивает шифрования и аутентификации.** ID отправителя не доказывает его личность.

## Структура пакета

```lua
{
  version = 1,
  kind = "status",
  request_id = "example-001",
  payload = { state = "ready" }
}
```

Проверяйте тип таблицы, версию, `kind`, обязательные поля, диапазоны значений и размер данных.

Используйте отдельные имена протоколов, например `"example.status.v1"`. Не исполняйте код, полученный по сети; недопустимо применять `load` к случайным сетевым строкам.

## Обработка сбоев

- Устанавливайте тайм-ауты для запросов.
- Сопоставляйте ответы с запросами по ID.
- Учитывайте возможные повторы сообщений.
- Проверяйте наличие модема.
- Реализуйте ограниченные повторные попытки.
- Не создавайте бесконечных сетевых циклов повторной отправки.

## Низкоуровневый модем

`modem.open(channel)`, `modem.transmit(channel, replyChannel, value)` и событие `modem_message` используются для прямой работы с каналами отдельно от Rednet.

HTTP-запросы зависят от конфигурации CraftOS и сетевых правил. Дескрипторы ответов необходимо закрывать.

Источники: https://tweaked.cc/module/rednet.html, https://tweaked.cc/peripheral/modem.html
