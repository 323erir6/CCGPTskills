# Тестирование и развёртывание

## Уровни проверки

1. **Синтаксис:** Компиляция файлов `.lua` совместимым парсером (CI использует Lua 5.3).
2. **Чистая логика:** Детерминированные модульные тесты без зависимостей от CraftOS.
3. **Среда CraftOS:** Проверка `require`, событий и терминала внутри Minecraft или подходящего эмулятора.
4. **Интеграция периферии:** Тестирование реальных подключённых устройств и конкретных версий модов.
5. **Полный сценарий:** Проверка перезагрузок, ошибок, отключения устройств и потери связи.

## CI

В репозитории есть GitHub Actions `.github/workflows/lua-ci.yml`, проверяющий синтаксис Lua 5.3 и выполняющий тесты `math3d`, `pid`, `round` и `sublevel_pose`. Workflow GOCODE дополнительно проверяет Python/Lua-симуляторы в Ubuntu и JSON-runner для обычного ChatGPT в Windows. Успешный CI **не гарантирует** работу периферии модов внутри игры.

## Развёртывание

Копируйте на CraftOS только нужные файлы и зависимости. Явно настраивайте имена устройств, не исполняйте произвольные скачанные программы. Отдельно проверяйте автозапуск: `startup.lua` может выполняться автоматически после загрузки компьютера.

## Воспроизводимые отчёты

Записывайте версии Minecraft, CC:Tweaked, загрузчика, модов, имена периферии, входные условия, ошибки и результаты тестов. Не подменяйте проверяемые факты предположениями.
