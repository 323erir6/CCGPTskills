# Начало работы с CC:Tweaked

CC:Tweaked выполняет программы CraftOS на Lua внутри компьютеров, черепах и карманных компьютеров Minecraft. Примеры используют встроенные API, а не окружение обычного настольного Lua.

## Первая программа

1. Открыть компьютер и запустить `edit hello`.
2. Ввести `print("Hello, CraftOS!")`.
3. Сохранить файл и выполнить команду `hello`.
4. Посмотреть подключённые устройства встроенной командой `peripherals`.

## Модель выполнения

- У каждого компьютера CraftOS есть очередь событий. `os.pullEvent()` ждёт событие и обычно прерывает программу при Ctrl+T.
- `sleep(seconds)` отдаёт управление среде; избегайте бесконечных циклов без ожидания.
- `parallel.waitForAny` и `parallel.waitForAll` обеспечивают кооперативное переключение, а не реальные потоки ОС.
- При работе с цветом учитывайте `term.isColor()`.
- API `turtle` доступен только черепахам. Дополнительная периферия требует соответствующих модов.

## Структура файлов

Отделяйте точку входа от модулей конфигурации, сети, устройств, интерфейса и управления. Для повторного использования подходит `require`.

## Проверка версий

Записывайте версии Minecraft, CC:Tweaked, загрузчика и периферийных модов, а также точные имена устройств. Методы сторонних устройств надо сверять с установленной версией через `peripheral.getNames()` и `peripheral.getMethods(name)`.

## Запуск примеров

Скопируйте `.lua` в компьютер CraftOS и запустите по имени файла. Модули из `lib/` копируются отдельно и импортируются через `require`.

Источники: https://tweaked.cc/, https://tweaked.cc/module/peripheral.html
