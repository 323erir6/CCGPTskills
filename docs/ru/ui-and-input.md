# Интерфейсы и ввод

Обычные терминалы и мониторы CC:Tweaked отображают символы, а не произвольные пиксели. Координаты начинаются с 1, расположение элементов следует пересчитывать по `getSize()` при изменении размера.

## Отрисовка

Для локального терминала используйте `term.setCursorPos(x, y)`, `term.write(text)`, `term.clear()`. Монитор поддерживает похожие методы и `setTextScale(scale)`. При использовании `term.redirect(monitor)` восстанавливайте исходный терминал после завершения.

Не перерисовывайте весь экран после каждого постороннего события. По возможности обновляйте только изменённые строки.

## Ввод

- Терминал: `mouse_click`, `mouse_drag`, `mouse_scroll`, `key`, `char`, `paste`.
- Продвинутый монитор: `monitor_touch` (имя монитора и координаты).
- Изменение размера: `term_resize`, `monitor_resize`.

Проверяйте координаты касания по текущим размерам и учитывайте возможность отключения устройства.

## Цвет

Возможности цветных и монохромных устройств отличаются. Проверяйте `term.isColor()` или соответствующий метод вывода перед использованием палитр.

## Внешние GPU

GPU из сторонних модов могут иметь другие разрешения, системы координат, методы рисования, синхронизации кадров и события ввода. API надо проверять для конкретной версии.

Источники: https://tweaked.cc/module/term.html, https://tweaked.cc/peripheral/monitor.html
