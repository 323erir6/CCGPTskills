# CBC Realistic Ballistics 1.9.22 — взаимодействие с CC

**Исходники:** [CBC-Realistic-Ballistics](https://github.com/323erir6/CBC-Realistic-Ballistics), коммит `a09920888421b15de1fe7d92cc01e0731ba6c725`; версия **1.9.22**, Minecraft 1.21.1, Create 6.0.10, CBC 5.11.7. Идентификатор мода — `cbc_realistic_ballistics`.

## API CC:Tweaked

**В JAR не обнаружено прямых ссылок на CC:Tweaked или собственной Lua-периферии.** Мод реализует физику снарядов, столкновения, сохранение полёта и оптимизации через Java/NeoForge. Не путайте его с **CBC Going Ballistic** — это отдельный публичный мод, отсутствующий в проверенном архиве.

Данные для CC-программ предоставляют другие моды:
- CBC Programmable Fuzes: `getLoadedProjectileInfo()`, `getLoadedPropellantInfo()`, `getCannonInfo()`.
- NeoPeripheral/CBC: методы установки пушки и управления состоянием.
- Радарные и физические периферии: координаты и скорости.

## Что изменяет физическая модель

- Полёт рассчитывается по модифицированной физической модели с массой, сопротивлением, плотностью атмосферы и гравитацией.
- Используются профили боеприпасов и переопределения номинального калибра.
- В новых версиях полёт и состояние снарядов могут сохраняться при отсутствии чанков и после рестарта.
- Проверки столкновений учитывают последовательные участки реальной траектории; неизвестные чанки у земли не объявляются пустотой.
- Сохраняются необходимые механики проникновения и разрушения CBC.
- Присутствуют оптимизации жизненного цикла и совместимости с дополнениями.

**Не используйте `physicalDiameterMetres` из телеметрии боеприпаса как гарантированный номинальный калибр.** Это размер хитбокса. Для точного предсказания необходимы масса, сопротивление, атмосфера, угол и версия конкретного профиля.

## Требования к отдельному офлайн-калькулятору

1. Таблица соответствий registry ID и баллистического профиля.
2. Все ключи конфигурации с единицами, стандартными значениями и ограничениями.
3. Проверенные формулы гравитации, плотности атмосферы, сопротивления.
4. Шаг интегрирования и связь с игровыми тиками.
5. Масса, эффективная площадь, ветер и модификаторы дальности.
6. Специальные параметры CBC AT, Military Supplement и других боеприпасов.
7. Тесты совпадения с траекториями внутри игры.

Здесь **нет выдуманного баллистического калькулятора**: он должен строиться по точным константам конкретной установленной версии.

## Совместимость

Programmable Fuzes предоставляет дополнительные методы CC; Aero Velocity Fix и High Altitude Transit корректируют серверную физику; частота исполнения Lua зависит от Sable CC Tick Sync.
