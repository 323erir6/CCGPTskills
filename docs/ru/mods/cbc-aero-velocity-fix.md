# CBC Aeronautics Velocity Fix 1.0.7 — без API CC

**JAR в сборке:** `cbc_aero_velocity_fix-1.0.7.jar`, Mod ID `cbc_aero_velocity_fix`. Публичный репозиторий с исходниками в проверенном списке отсутствует.

## Поддержка CC:Tweaked

Сканирование классов JAR не выявило собственной периферии, глобального Lua API или аннотаций `@LuaFunction`. Мод исправляет физическое поведение, но **не добавляет программируемых команд CC**.

Внутренние метаданные NeoForge описывают добавление скорости конструкции к скорости снаряда Create Big Cannons. Это не то же самое, что предотвращение прохождения **целых конструкций** друг сквозь друга на высокой скорости. Точное назначение следует выяснять по Mixin/исходникам, а не по похожему названию.

## Зависимости из метаданных

Minecraft 1.21.1, NeoForge 21.1.219+, Create Big Cannons 5.11+, Sable 1.2+. Дополнительные необязательные интеграции: `cbc_at`, `cbc_equally_opposite`, `cbc_going_ballistic`.

## Диагностика

Для скорости запуска снарядов сравнивайте исходную скорость конструкции и начальную скорость снаряда в контролируемом тесте. Для прохождения целых физических тел через препятствия исследуйте отдельную систему столкновений, пока код патча не подтвердит обратное.

**Статус:** метаданные и отсутствие прямых ссылок на CC проверены; детали реализации не установлены.
