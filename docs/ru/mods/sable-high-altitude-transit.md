# Sable High Altitude Transit 1.3.5

**Мод:** [Sable-High-Altitude-Transit](https://github.com/323erir6/Sable-High-Altitude-Transit), версия из `gradle.properties` — **1.3.5**, коммит `f3330cbca139f6e62154c04cb05df22e225810bf`.

## Наличие API CC:Tweaked

**Отдельных Lua-функций, модулей ILuaAPI или периферии IPeripheral в просмотренных исходниках не найдено.** Мод изменяет физику Sable и загрузку чанков на сервере, то есть условия работы CC-программ, но не их набор функций.

## Влияние на программы

- На большой высоте Sable может продолжать симуляцию конструкции без загрузки обычных чанков земли под ней.
- Основной порог — **нижняя точка конструкции Y=400**; в измерениях с другой верхней границей используется специальное условие над потолком мира, см. актуальный код.
- Физическое движение, команды, перевозка игроков и отслеживание конструкций продолжаются.
- При снижении возвращается обычное взаимодействие с terrain-чанками.
- Оптимизации не означают, что все неизвестные или незагруженные участки мира автоматически считаются пустотой.
- Для координат и скоростей по-прежнему применяются `CC:Sable`, `NeoPeripheral sable_engine` и другие реальные источники данных.

## Проверки

1. Считайте `sublevel.getLogicalPose()` и `sublevel.getVelocity()`.
2. Проверьте движение тела на высоте выше порога.
3. Изучите журнал сервера с сообщениями `[Transit perf]`.
4. Отдельно проверьте снижение и взаимодействие с реальным рельефом.
5. Не считайте высоту гарантией стабильной частоты или отсутствия задержек.

Владелец Lua API — CC:Sable/NeoPeripheral; этот мод изменяет физическую среду. Несуществующие функции вида `highAltitudeTransit.*` использовать нельзя.
