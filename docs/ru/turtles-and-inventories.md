# Черепахи, инвентари и автоматизация хранения

## Движение черепахи

API `turtle` доступен только черепахам. Основные команды: `forward`, `back`, `up`, `down`, `turnLeft`, `turnRight`, `inspect`, `getFuelLevel`, `select`, `getItemDetail`.

Движение возвращает признак успеха и иногда причину отказа. Проверяйте результат каждой команды. Топливо может возвращаться строкой `"unlimited"`, поэтому не всегда допустимо сравнение с числом.

Не разрушайте блоки автоматически без необходимости. Сначала применяйте `inspect`, ограничивайте длину маршрута и останавливайтесь перед препятствием.

## Периферия инвентаря

Стандартный интерфейс может предоставлять `size()`, `list()`, `getItemDetail(slot)`, `pushItems(toName, fromSlot, limit, toSlot)`, `pullItems(fromName, fromSlot, limit, toSlot)`. Не каждый контейнер доступен в качестве периферии.

`list()` возвращает разреженную таблицу с номерами слотов. Для её обхода применяется `pairs`, а не `ipairs`.

При переносе предметов проверяйте имена устройств, доступность метода и фактическое количество перемещённых предметов.

## Проверки

Начинайте с одного контейнера и одного предмета. После каждого перемещения проверяйте результат. Для черепах сверяйте фактическую конечную позицию до расширения маршрута.
