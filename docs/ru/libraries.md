# Модули Lua для повторного использования

## Установка

Скопируйте `lib/` в корневую папку компьютера CraftOS. При подходящем пути поиска загрузите, например, `local math3d = require("lib.math3d")`. Модули не скачивают сторонних зависимостей из сети.

| Модуль | Назначение |
| --- | --- |
| [math3d.lua](../../lib/math3d.lua) | Углы wrapDegrees, shortestError; векторы vec/add/subtract/scale/dot/length/normalize/distance; направление, вычисление скорости, продольная скорость и перевод в км/ч |
| [round.lua](../../lib/round.lua) | Округление десятичных чисел с половинами от нуля для положительных и отрицательных значений |
| [sublevel_pose.lua](../../lib/sublevel_pose.lua) | CC:Sable: кватернионы, мировые/локальные координаты, углы ориентации, направление и проекция скорости |
| [pid.lua](../../lib/pid.lua) | Дискретный PID с ограничением интеграла и выхода, базовая защита от накопления интеграла |
| [peripherals.lua](../../lib/peripherals.lua) | Список периферии, проверка методов и безопасные вызовы |
| [protocol.lua](../../lib/protocol.lua) | Версионированные сетевые пакеты и проверка полей; НЕ шифрование и НЕ аутентификация |
| [config.lua](../../lib/config.lua) | Пространство имён настроек CraftOS, загрузка, получение, сохранение и проверка типов |

## Соглашения

- Периоды `dt` в вычислениях скорости и PID задаются в секундах.
- `wrapDegrees`, `shortestError` и углы Sublevel работают в градусах.
- Кватернион CC:Sable задаётся `a` и `v.x/v.y/v.z`.
- `localToWorld` учитывает pivot, масштаб, поворот и перенос; для векторов направления используйте поворот без переноса.
- Коэффициенты PID нужно настроить под реальную физическую систему.
- Модуль `protocol` проверяет структуру пакета, но не обеспечивает шифрования и подтверждения отправителя.
- Перед обращением к периферии проверяйте существование соответствующих методов.
