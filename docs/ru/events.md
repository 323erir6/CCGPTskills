# События и кооперативная многозадачность

Программы CraftOS должны обрабатывать ввод, таймеры и периферию, не блокируя очередь событий.

## Основные события

| Событие | Дополнительные аргументы |
| --- | --- |
| `timer` | идентификатор таймера |
| `rednet_message` | ID отправителя, сообщение, протокол |
| `modem_message` | сторона, канал, обратный канал, сообщение, дистанция |
| `monitor_touch` | имя монитора, x, y |
| `mouse_click` | кнопка, x, y |
| `key` | код клавиши, признак удержания |
| `peripheral` | имя подключённого устройства |
| `peripheral_detach` | имя отключённого устройства |
| `redstone` | без дополнительных аргументов |

## Таймеры

`os.startTimer(seconds)` возвращает ID. Необходимо сверять его с ID в событии: другие части программы тоже могут создавать таймеры.

```lua
local id = os.startTimer(1)
while true do
  local event, value = os.pullEvent()
  if event == "timer" and value == id then
    print("One second elapsed")
    break
  end
end
```

## Parallel

`parallel.waitForAny` завершается после первого закончившегося обработчика; `parallel.waitForAll` ждёт всех. Переключение происходит только при уступке управления.

Не создавайте несколько независимых читателей одного логического потока событий без диспетчера.

## Завершение

Обычно нужно использовать `os.pullEvent`, чтобы Ctrl+T мог остановить программу. `os.pullEventRaw` не обрабатывает прерывание стандартным способом, поэтому его применение требует обоснования.
